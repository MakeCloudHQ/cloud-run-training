# Cloud Run Training

Welcome! This repository contains materials for a comprehensive training session on Google Cloud Platform and Cloud Run.

## Session Overview

This training is designed for teams with mixed experience levels in GCP, covering fundamentals through advanced Cloud Run deployment strategies.

### Duration: 4-5 hours

## Agenda

### 1. GCP Basics (1-2 hours)
Introduction to Google Cloud Platform fundamentals for teams with mixed experience levels.

**Topics Covered:**
- Projects and Folders - Organizational hierarchy
- Networking - VPCs, subnets, and connectivity
- IAM - Identity and Access Management fundamentals
- Interactive Q&A and discussion

**Materials:** [01-gcp-basics/](./01-gcp-basics/)

---

### 2. Cloud Run Basics (1 hour)
Hands-on introduction to deploying and managing Cloud Run services.

**Topics Covered:**
- Container basics and Cloud Run architecture
- Hands-on lab: Deploy your first Cloud Run service
- Understanding revisions, traffic splitting, and basic configuration

**Materials:** [02-cloud-run-basics/](./02-cloud-run-basics/)

---

### 3. Cloud Run Advanced (1-2 hours)
Deep dive into production-ready Cloud Run deployments and migration strategies.

**Topics Covered:**
- Infrastructure as Code: gcloud vs Terraform
- VPC networking and serverless VPC access
- Scaling strategies and performance optimization
- Common gotchas and how to avoid them
- Migration strategies from GKE to Cloud Run

**Materials:** [03-cloud-run-advanced/](./03-cloud-run-advanced/)

---

## Prerequisites

Before the session, please complete the setup steps in [setup-instructions.md](./setup-instructions.md).

**You will need:**
- Google Cloud Platform account with Owner access to a project
- `gcloud` CLI installed and authenticated
- Docker Desktop installed (for local testing)
- Text editor or IDE of your choice
